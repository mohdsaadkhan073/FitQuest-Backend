# FitQuest Exercise Recognition Model

Modular computer-vision exercise recognition and repetition-counting system built with **Python**, **MediaPipe Pose**, and **OpenCV**.

Located inside `backend/model/`.

## Running the Model

Run from the `FitQuest/` project root directory:

```bash
python backend/model/main.py
```

## Keyboard Controls

- `1`: Switch to **Squats**
- `2`: Switch to **Push-ups**
- `3`: Switch to **Jumping Jacks**
- `r`: **Reset** rep count
- `q` / `ESC`: **Quit**
